\# World Population Density Analysis (1960–2016)



\## Problem or Research Question

This project investigates the historical trends and patterns of global population density from 1960 to 2016, specifically comparing the trajectories of selected European countries (such as Germany and Switzerland) to understand long-term demographic growth.



\## Dataset Source and Usage Permissions

\- \*\*Dataset\*\*: World Population Density dataset (sourced from World Bank indicators).

\- \*\*Usage Permissions\*\*: Open-source educational use and public research data.



\## Methods and Tools Used

\- \*\*Programming Language\*\*: Python 3\[cite: 3]

\- \*\*Libraries\*\*: 

&#x20; - `pandas` for data manipulation, cleaning, and filtering\[cite: 3]

&#x20; - `Bokeh` for building interactive visualizations, line charts, and grid layouts\[cite: 3]

\- \*\*Environment\*\*: Jupyter Notebook / VS Code\[cite: 3]



\## Key Findings and One Limitation

\- \*\*Key Findings\*\*: 

&#x20; - Both Germany and Switzerland exhibited a steady, consistent increase in population density over the observed decades\[cite: 3].

&#x20; - Multi-plot grid layouts effectively highlight comparative growth rates and structural differences between the two countries\[cite: 3].

\- \*\*Limitation\*\*: 

&#x20; - The dataset contains missing values (`NaN`) for certain countries and specific years (such as recent post-2015 updates), which limits complete temporal continuity for all entities\[cite: 3].
